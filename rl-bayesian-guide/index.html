01. 확률과 베이즈

기댓값: \(\mathbb E[X]=\sum_x p(x)x\)

확률로 가중평균을 만든다. 이것이 RL의 기대보상 목표에도 사용된다.

조건부 확률: \(P(A|B)=P(A,B)/P(B)\)

베이즈 법칙: \(p(z|x)=p(x|z)p(z)/p(x)\)

Prior는 사전 믿음, likelihood는 관측의 설명력, posterior는 관측 후 갱신된 믿음이다.

숫자 예시

사전 질환율 1%, 민감도 90%, 위양성률 5% → 양성인 경우 실제 질환일 확률

\(P(D|+)=\frac{0.9\cdot0.01}{0.9\cdot0.01+0.05\cdot0.99}\approx15.4\%\)
\(D_{KL}(q\|p)=\mathbb E_q[\log(q(z)/p(z))]\ge0\)

KL은 분포 간 불일치이며 대칭이 아니다. VAE의 posterior 정규화와 RLHF의 reference policy 규제에 모두 등장한다.

02. MDP와 Bellman

state \(s_t\)policy \(\pi(a|s)\)action \(a_t\)reward, next state
\(G_t=\sum_{k\ge0}\gamma^k r_{t+k},\quad J(\theta)=\mathbb E_{\pi_\theta}[G_0]\)

\(V^\pi(s)=\mathbb E[G_t|s_t=s]\), \(Q^\pi(s,a)=\mathbb E[G_t|s_t=s,a_t=a]\), \(A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)\).

\(V^\pi(s)=\mathbb E[r_t+\gamma V^\pi(s_{t+1})|s]\)

Dynamic Programming은 모델의 전이 확률을 알 때 Bellman backup을 반복. Q-learning은 \(r+\gamma\max_{a'}Q(s',a')\), SARSA는 실제 다음 행동을 사용한 \(r+\gamma Q(s',a')\)로 TD 업데이트한다.

03. Policy Gradient → REINFORCE

\(\nabla_\theta J=\mathbb E[\sum_t\nabla_\theta\log\pi_\theta(a_t|s_t)G_t]\)

잘된 행동의 log-prob을 높인다. Action에 독립적인 baseline \(b(s_t)\)을 빼면 기대 gradient는 그대로이고 variance는 줄어들 수 있다.

\(\hat g=\sum_t\nabla_\theta\log\pi_\theta(a_t|s_t)(G_t-b(s_t))\)

Critic과 GAE

\(\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)\)

\(\hat A_t^{GAE}=\sum_{l\ge0}(\gamma\lambda)^l\delta_{t+l}\)

Critic은 value를 예측하고, actor는 advantage에 따라 policy를 수정한다.

04. PPO — clipped policy update

Old policy rolloutsCritic + GAEMinibatch epochsNew policy
\(\rho_t=\pi_\theta(a_t|s_t)/\pi_{old}(a_t|s_t)\)

\(L=\mathbb E[\min(\rho_t A_t,\operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)A_t)]\)

Good action 확률이 너무 커지는 경우나 bad action 확률이 너무 작아지는 경우 추가 최적화 이득을 제한한다. 엄격한 KL 보장은 아니다.

PPO는 single rollout 방법이 아니다. 여러 prompt, trajectory를 수집하는 rollout batch와 학습용 minibatch, GPU 메모리용 microbatch는 서로 다른 개념이다.

05. GRPO와 RLOO

1 promptG completionsRewardsRelative advantage

GRPO

\(A_i=(R_i-\bar R)/(\mathrm{std}(R)+\epsilon_{num})\)

Critic 없이 같은 프롬프트 응답의 상대 보상으로 advantage를 만들고 PPO-style ratio clipping을 사용한다. 응답 보상이 전부 같으면 상대 정보가 사라진다.

RLOO

\(A_i=R_i-\frac1{G-1}\sum_{j\ne i}R_j\)

자기 자신의 reward를 baseline에서 제외한 REINFORCE. Critic과 clipping은 필수 아님.

예: rewards [1,0,0.5,0.5] → RLOO advantages [+0.667, −0.667, 0, 0].

06. SAO — 2026 Single-Rollout Asynchronous Optimization

Async actor1 rollout / promptValue model + GAEToken clipping

Hou et al. (2026). 비동기 Agent RL에서 프롬프트당 하나의 trajectory만 생성. 가치 모델을 활용해 advantage를 추정하고 policy lag / off-policy 문제를 완화하는 clipping을 설계한다. PPO가 반드시 다중 rollout이라는 뜻은 아니다. 논문은 SWE-Bench Verified 등에서 이점 보고; 일반적인 보장 아님.

07. VAE → IWAE

Input xEncoder q(z|x)z=μ+σεDecoder p(x|z)
\(\log p_\theta(x)=\log\int p_\theta(x,z)dz\)

이 적분이 어려워 변분 posterior를 도입한다.

\(ELBO=\mathbb E_{q_\phi}[\log p_\theta(x|z)]-D_{KL}(q_\phi(z|x)\|p(z))\)

IWAE는 K개 latent 중요도 가중치로 하한을 강화한다.

\(L_K=\mathbb E\left[\log\frac1K\sum_{k=1}^K\frac{p_\theta(x,z_k)}{q_\phi(z_k|x)}\right]\)

K=1은 VAE ELBO. 샘플 수가 늘면 bound가 통상 타이트해지지만 계산비용과 encoder gradient 문제가 있을 수 있다.

08. Diffusion (DDPM)

Clean imageForward noiseGaussian xTReverse denoiseNew image
\(x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon\)

\(L_{simple}=\mathbb E[\|\epsilon-\epsilon_\theta(x_t,t)\|^2]\)

모델은 임의 단계의 noise를 예측하고, 생성에서는 순수 잡음으로부터 반복적으로 역과정을 수행한다. DDPM의 variational objective에서 파생된 대표적 단순화 손실.
